# Распределение мест в общежитии

Приложение предназначено для учета заявок на проживание, размещения жильцов по комнатам и оформления переселений.

## Основные сущности

- Пользователь: человек, который подает заявку на проживание.
- Комната: номер, вместимость и доступность для заселения.
- Заявка на проживание: пользователь, время подачи и статус рассмотрения.
- Договор проживания: заявка, комната, даты проживания и статус договора.
- Заявка на переселение: договор, желаемая комната, время подачи и статус.

Свободные места рассчитываются по вместимости комнаты и количеству ее действующих договоров.

## Бизнес-операции

1. Заселение. По новой заявке создается действующий договор, заявка становится одобренной. Комната должна быть открыта и иметь свободное место, а у пользователя не должно быть другого действующего договора. Дата заселения назначается текущая.
2. Отмена заявки. Новая заявка на проживание переводится в статус отмененной. Обработанную заявку отменить нельзя.
3. Продление проживания. У действующего договора с неистекшим сроком изменяется дата окончания. Новая дата должна быть позже прежней.
4. Выселение. Действующий договор и исходная заявка завершаются, датой выезда становится текущая дата. Необработанные заявки на переселение по этому договору отменяются, место освобождается.
5. Переселение. По новой заявке меняется комната действующего договора с неистекшим сроком. Целевая комната должна быть другой, открытой и иметь свободное место. Заявка становится одобренной, остальные необработанные заявки на переселение этого договора отменяются.
